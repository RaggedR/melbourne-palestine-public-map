# Melbourne Palestine organising — public map

Interactive graph of **public** Melbourne Palestine movement accounts, layers, splits, and places.

- Mass movement, militant-public disruption, and anonymous after-the-fact cells are drawn as separate layers.
- Click a node to open its Instagram, website, calendar, or map in a new tab.
- This is not a people-targeting graph. Private Signal rooms and encrypted job boards are not included.

Live: <https://raggedr.github.io/melbourne-palestine-public-map/>
